HTML DERS 1: HTML NEDİR?

HTML ne işe yarar?

HTML, web sitelerinin iskeletini oluşturur.

Başlıklar, yazılar, resimler ve bağlantılar HTML ile eklenir.

İlk HTML kodumuz

<!DOCTYPE html>
<html>
<head>
    <title>İlk Sitem</title>
</head>
<body>
    <h1>Merhaba Dünya!</h1>
    <p>İlk web sitemi yapıyorum.</p>
</body>
</html>

📚 Kodların anlamı

html: Web sayfasının ana yapısı.

head: Sayfa bilgileri.

title: Tarayıcı sekmesindeki başlık.

body: Sayfada görünen içerik.

h1: Büyük başlık.

p: Paragraf.

🎯 Öğrenci görevi

Kendi ismini kullanarak bir başlık oluştur.
